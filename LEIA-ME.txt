SERVNET — PORTAL DA CARTEIRINHA

REQUISITOS
- Node.js 18 ou superior
- npm
- Docker Desktop (para iniciar o PostgreSQL local) ou um banco PostgreSQL acessível

CONFIGURAÇÃO LOCAL
1. Instale as dependências: npm install
2. Copie .env.example para .env e defina uma senha administrativa forte.
3. Inicie o banco: docker compose up -d db
4. Crie as tabelas: npm run migrate
5. Crie a conta TI/CPD: npm run seed:admin
6. Em um terminal: npm run start:api
7. Em outro terminal: npm run dev
8. Abra o endereço local informado pelo Vite.

O login da TI/CPD usa ADMIN_USERNAME e ADMIN_PASSWORD do arquivo .env.

SEGURANÇA
- Senhas ficam no banco apenas como hash Argon2id.
- Associados e administradores usam sessão no servidor.
- A importação CSV aceita as colunas nome e matricula.
- As senhas provisórias importadas são baixadas em um arquivo separado; entregue-as diretamente aos associados.
- O repositório é público. Nunca coloque .env, dados reais ou segredos no GitHub.
- Os dados ilustrativos da tela inicial servem apenas para representar o visual; não são contas válidas.
